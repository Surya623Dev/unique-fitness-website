# Unique Fitness — Gym Landing Page Prototype

A dark cinematic, black-metallic and neon-lime landing page prototype for **Unique Fitness**.

## Included
- Responsive landing page sections: hero, gym overview, facility gallery, programs, trainers, testimonials, membership plans and contact CTA.
- Interactive program cards, monthly/yearly pricing toggle, responsive mobile menu and free-trial demo modal.
- Motion effects and reduced-motion support.
- Visual concept reference image (`visual-concept.png`).

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Deployment
This is a static website that can be deployed using Netlify or GitHub Pages. The trial enquiry form is a frontend demo only; connect a backend or CRM before using it for real leads.

## Before production
Replace sample stock imagery, trainer profiles, testimonial, contact details, opening hours and illustrative membership prices with verified gym information. External images and Google Fonts require an internet connection.
